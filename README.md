# Wildfire 本地大厅与英雄菜单恢复

针对《无尽战区》旧客户端 1.0.192 的可复现离线恢复项目。需要自行准备原客户端；仓库保存补丁生成器和本地启动代码。

2026-10-13 已通过真实客户端截图和启动日志验证：无需服务器登录，即可进入原版大厅 `zc_new01`，显示本地英雄和场景。代码中的地图配置名是“伦敦”；用户熟悉的大厅/区服名称为“深海堡垒”。当前不是完整服务端，在线角色资料、房间、组队和服务器 NPC 尚未恢复。

## 复现已验证大厅

需要 Windows、Python 3.11+ 和原游戏运行环境。从项目目录执行：

```powershell
python tools/build_client.py --source "C:\你的客户端目录" --output "C:\offline_hall" --profile hall
```

`--source` 指向同时包含 `game` 与 `res` 的目录。双击生成的 `start_offline.cmd`；出现“建议使用 launch.exe”的提示时点“确定”，再等待加载。启动器会恢复独立保存的启动模板，防止原客户端退出时改写 `EditorConf.py` 后丢失自动进入大厅功能。

仅检查补丁是否与已验证版本完全一致：

```powershell
python tools/build_client.py --source "C:\你的客户端目录" --verify-only
```

## 如何实现

1. 安全解析资源包里的 Python 2.7 marshal 对象，定位现存离线状态机与测试界面。
2. 局部恢复 `ST_OFFLINE` 的 `DebugManager` 注册，以及隐藏的单机测试选项；保持全局发行版标识。
3. 将离线默认地图改为 `zc_new01`，使用地图内有效坐标 `(69,229,223)`。
4. 重算资源条目的加密 MD5，保持 BAG 总长度、索引偏移和条目长度。
5. 独立副本以普通用户权限启动，并通过本地 `EditorConf.py` 延迟进入离线状态。

生成器先核对原始文件 SHA256，遇到其他版本会停止。原始目录不做补丁修改，输出中的 `wf.exe` 与 `entities.bag` 是独立副本。其他素材可能通过硬链接复用，禁止直接改写这些素材文件。修改副本 EXE 的权限清单会使其原数字签名失效。

## 英雄列表与切换

已恢复原头像列表和离线切换英雄，并实际验证模型切换、重启保留英雄。使用 `--profile heroes` 生成菜单版，H 打开/收起列表，点击或双击头像切换英雄。H 的重复打开与切换已由实体键盘验证。细节见 [英雄菜单说明](docs/hero-menu.md)。`milestones/offline-hall/EditorConf.py` 保留大厅启动代码；菜单开发使用 `runtime`，不覆盖该里程碑。

详细验证与开发记录见 `docs`。Python 2 客户端脚本由游戏自身执行；分析工具不会在宿主 Python 中执行解出的游戏代码。
