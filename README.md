# Wildfire 本地大厅与原版英雄页面恢复

《无尽战区》客户端 1.0.192 的离线恢复项目。仓库只保存补丁生成工具、运行脚本和验证记录；原客户端及素材需自行准备。

## 启动与操作

本机双击入口是 `C:\wildfire-gpt\offline_client\开始游戏.exe`，它运行旁边的 `start_offline.cmd`。入口会恢复被原游戏退出流程改写的启动模板，再运行根目录的本地 `launch.exe`；适配器使用当前客户端实际支持的 `-redirect` 参数，随游戏退出而结束。已复测无需点击启动警告即可进入大厅。

- 大厅使用原来的 WASD 移动，鼠标转视角；Ctrl 按一次显示光标，再按一次隐藏。
- 点击大厅顶部“英雄”或按 Z 打开／关闭英雄页。
- 菜单内 Esc 或左上返回箭头返回大厅；大厅 Esc 显示退出确认。
- 退出确认框内再次按 Esc 取消退出；回车打开原版大厅聊天输入，回车或 Esc 收起。离线聊天不接服务器发送。
- Z 固定打开英雄页，X 打开时装页，C 打开语音页，V 打开故事页；同一按键再次按下返回大厅。出装、喷漆使用原顶部页签。
- B 开关原版背包，分类浏览此客户端的全部物品；每页复用 56 个格子，不每帧扫描物品表。
- 左上角“练习”打开原版六边形入口，点击“练习场”进入本地训练地图。顶部 F1–F6 菜单支持快捷键和光标点击，增加“选择地图”；F3/F4 换英雄／对手，Y 开关练习 AI，B 初始化，L 升级、Shift+L 满级。左下数字键购买和升级装备，波浪键撤销，F2 出售；技能冷却同步 HUD。大厅禁止攻击且滚轮缩放，练习场滚轮使用原版技能。Esc 收起菜单后确认返回大厅。具体恢复范围见 [练习场说明](docs/offline-practice.md)。
- 大厅滚轮向上拉近、向下拉远；上下视角可到接近垂直，保留垂直方向的数学边界以避免翻转。练习场滚轮使用英雄技能。
- 出生位置在大厅中央。角色近距离淡化关闭，切页及切回窗口保留实际视角，默认 80 FPS；右上角设置 → 画质 → 帧率控制可选 60、80、120、144、165、240 或不限制，点击确定保存。垂直同步开启时还受屏幕刷新率限制。
- 六边形英雄列表用于预览；原“源力塑形”按钮应用所选英雄。
- 时装页使用原版“英雄时装／所有时装”界面、品质筛选、翻页、染色和配饰布局。现有时装、配饰和染色剂在离线档案中可用，保留原英雄兼容范围，退出页面后应用到大厅人物。

旧的 H/F6 简易选择菜单、错误的旧角色资料页面和多套 profile 入口已从当前运行代码移除。只保留一套离线入口；旧实验保留在 Git 历史中。

## 重建客户端

需要 Windows、Python 3.11+、Windows .NET Framework 4 编译器与原游戏运行环境。`--source` 指向包含 `game` 和 `res` 的原客户端目录：

```powershell
python tools/build_client.py --source "C:\你的客户端目录" --output "C:\offline_client"
```

已有副本只更新运行脚本：

```powershell
python tools/deploy_runtime.py --client "C:\offline_client"
```

核对可复现的二进制补丁：

```powershell
python tools/build_client.py --source "C:\你的客户端目录" --verify-only
```

生成器核对原始 SHA256 后，恢复客户端现存 `ST_OFFLINE` 状态、单机入口和 `zc_new01` 大厅场景，重算 BAG 条目的加密 MD5。独立副本的 EXE 权限清单改为普通用户启动，并重算校验值。原始目录不修改；其他素材可能硬链接复用，禁止直接改写。

## 恢复范围与验证

大厅已由真实客户端画面和用户确认。英雄、时装、语音、故事、出装、喷漆六个页签使用客户端现存界面与数据；已在游戏内部验证页签加载、英雄筛选翻页、模型预览、塑形保存、故事文字、扩展语音播放和装备包打开。时装界面已核对实际画面，目录包含 309 条时装条目。用户已确认换装退出后的移动、鼠标视角、Ctrl 光标与切出／切回窗口均正常。

这仍是本地客户端恢复。历史账号背包、等级、胜率、付费记录、在线社区出装榜与匹配服务没有原服务器数据，不能据此恢复。背包展示本地物品目录，缺少原素材图标的条目保留问号占位。当前使用本地选择档案；未恢复的功能点击后无反应。尚未逐个验证所有时装、配饰、染色组合和出装编辑。具体进度见 [原版英雄页说明](docs/formal-hero-tabs.md)，本轮弹框与卡顿修复见 [启动与性能记录](docs/startup-performance.md)。

## 给好友使用

最直接的方式是将整个 `offline_client` 文件夹复制给好友，好友解压后双击 `开始游戏.exe`（也可使用 `start_offline.cmd`）。运行成品不需要 Python，也不需要登录账号。

若好友已有完整的同版本原客户端，可以用 `tools/package_friend_patch.py` 生成覆盖补丁包（包含独立客户端 EXE、已验证的脚本包、本地启动器及运行脚本，不包含个人档案、日志和调试命令）：

```powershell
python tools/package_friend_patch.py --client "C:\offline_client" --output "C:\wildfire-huitailang-patch.zip"
```

好友先复制一份完整原客户端，再将补丁解压到副本根目录，合并 `game`、`res`、`bootstrap` 并替换同名文件。补丁本身不包含模型、地图和声音素材，不能单独运行。GitHub 仓库仍只保存代码与文档；账号权限和仓库可见性不变。

旧客户端的 Python 2 脚本由游戏自身执行。资源分析器只解析 marshal 对象，不在宿主 Python 执行解出的游戏代码。
