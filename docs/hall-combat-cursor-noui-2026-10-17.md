# 大厅战斗光标、无 UI 模式与提示补充（2026-10-17）

本轮继续修改本地 runtime 并部署到 `C:\wildfire-gpt\offline_client`，未发布远程更新。

## 战斗状态改为练习场输入逻辑

- 大厅按 Tab 进入战斗后，输入方式与练习场一致：隐藏光标、`sendMouseMovementToScript(True)`、`FsmGame` 切到 `MOD_HERO`、启用原 Aim 准心，`move_only` 保持 False。
- 镜头和滚轮交给原版战斗相机：`handle_camera_mouse` 在战斗状态直接调用原相机处理，不再走大厅滚轮的拉近拉远；隐藏光标后也不再启动大厅的“按位置拖动”逻辑。
- 鼠标按下/松开仍转发给英雄，左键空白处普攻、Q/E/R/F/C 等技能键释放技能；WASD 与鼠标视角由原 FSM 处理。
- Tab 或 **Esc** 返回非战斗：恢复常驻光标、关闭准心、切回 `MOD_CITY`，Esc 不再直接弹退出确认（战斗里先退出战斗，再按一次才弹确认）。
- 聊天、背包、英雄/时装等页面、设置打开时会临时恢复光标并关闭准心；关闭后自动回到战斗状态。进入展示页或练习场会强制退出战斗。
- 焦点切出/切回沿用原逻辑：`sync_input_mode` 会按当前战斗状态重新开启脚本鼠标输入并恢复准心。

## 无 UI 模式（H）

- 大厅按 **H** 隐藏全部 UI：`guiManager` 中当前可见的界面元素全部隐藏，同时隐藏大厅导航栏、右下工具栏和聊天框；任何状态都会先记录“原本可见”的集合，退出时只恢复这些元素。
- 战斗状态下还会隐藏准心（只改 `aim.ring.visible`，不动 Aim 本身，避免战斗相机失去绑定导致视角乱转）。
- 再按 H 恢复；打开聊天、进入页签、开背包、进入练习场或按 Esc 都会先恢复 UI，避免在无 UI 状态下进入需要光标的界面。
- H 在聊天输入框中不生效（交给输入框），只在离线大厅且没有页面/聊天/设置/练习场入口时工作。
- 聊天框提示第 6 行写明“B 背包，H 隐藏/显示全部 UI，Esc 退出确认”，战斗提示第 1 行写明“Tab/Esc 返回非战斗”。
