维护入口：`C:/wildfire-gpt/offline_client/开始游戏.exe`。在原有客户端基础上更新；先前独立预览目录不再作为交付入口。原始客户端素材、EXE 和 BAG 保持不变。

## 使用

- 英雄装备页可穿脱场外装备，按英雄保存。目录包括普通、优质、精良、特种、本源五档；装备包复用原图标、提示和筛选。已实际操作诺斯武器穿脱并核对属性和保存结果。
- 大厅或练习场按 F8，点击原生六边形英雄列表中的英雄作为技能来源。再次 F8 或 Esc 收起；选择当前外观英雄可恢复自己的技能。A 的模型、时装保留，技能映射、行为资源、HUD 使用 B 的配置，按 A 保存。
- 练习场 F2 的按钮“红Buff 300 / 30秒”购买野怪加攻状态。有效期间重复点击不扣费，到期、初始化、换英雄／技能、换地图及离开练习场清理。已移除误加的药剂商店入口。
- 大厅聊天操作提示为四行，输入聊天时只保留一行收起提示。

## 实现与边界

新增模块 `offline_equipment.py`、`offline_buffs.py`、`offline_skillsets.py` 由现有构建／部署工具收集。内嵌 Python 缺少 Unicode 字面量解码器，新运行模块保持 ASCII 源码并使用 Unicode 转义。

跨英雄技能使用原生资源和行为图。不同骨骼、武器挂点、变身及召唤组合没有逐一验收；例如小满使用苏洛技能时，武器挂点可出现偏移。界面选择成功和行为就绪不能等同于所有英雄组合动作、命中均兼容。场外装备的目录和原生属性计算已接通，但没有逐条验收所有特殊被动／主动机制。

## 部署

正常退出游戏及启动器后，在仓库运行：

```powershell
python tools/deploy_runtime.py --client C:/wildfire-gpt/offline_client
```

保留现有本地档案，继续从原目录的 `开始游戏.exe` 启动。
