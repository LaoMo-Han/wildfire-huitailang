# 本地练习场

2026-10-14，客户端 1.0.192。代码在 `runtime/offline_practice.py`，通过现有启动器加载，不增加服务器或更改原素材包。部署命令仍是 `python tools/deploy_runtime.py --client C:/wildfire-gpt/offline_client`。

## 已接通

- 大厅练习按钮 → 原版 PracticeEntry 六边形菜单 → `zd_gangtyztest` → 返回大厅。
- 原版练习工具栏、选人列表、小地图、生命值、技能 HUD、伤害统计及装备进化栏。
- F3 切换玩家英雄并保存原离线选择；F4 选择客户端带有练习 AI 配置的对手。玩家仍可选现有全部英雄。
- 对手使用原版 PracticeAIHero、练习行为树及触发器。Y 开关 AI，难度按钮选初级／中级／高级，不向服务器发送请求。
- B 恢复生命和技能冷却、清空伤害并在地面重建对手；保留已有等级和装备。Shift+B 另重置等级、基础进化及金币。
- L 升一级，Shift+L 到 16 级。入场金币 90000；离场恢复进入前的金币、等级、装备数值和大厅视角。
- F1 技能说明、F2 进化树、F5 更换专属技能、F6 连招引导；顶部菜单同时支持光标点击。默认隐藏光标，回车打开聊天并显示光标，再按回车关闭并隐藏；Ctrl 不再切换光标，打开菜单时自动进入光标模式。
- 左下 1–5 先选装备类别，再按数字选分支完成一次购买；再次选同类继续升级。购买扣金币，数值属性和两个装备界面同步更新。
- 波浪键 `~`（反引号键）按交易顺序撤销最近购买／升级，退回原层级并全额返还本次花费。普通出售仅由 F2 进化树发起，使用原版出售价格；出售后清除撤销历史以避免重复退款。
- 顶部“选择地图”使用本地地图列表。切换后检测地面、重建练习对手、恢复 HUD，并保留等级、金币和装备；无有效出生地面的地图自动退回训练地图。地图加载期间不接受再次切换。
- 大厅可移动、普攻、释放技能，技能无 CD；大厅滚轮缩放。练习场滚轮交给原版 PlayerHero 技能输入，不再调整镜头距离。
- 技能 HUD 和实际施放检查共用 captain.cdmgr 冷却时钟，初始化补齐离线缺失的技能就绪记录。
- 练习场 F7 或顶部第二行“无CD”按钮开关无 CD 模式，默认关闭。切换立即清除当前冷却，开启期间后续技能也保持就绪；换英雄、重置、换地图保留当前开关，返回大厅始终无 CD。技能动画、引导和资源要求仍遵循原英雄规则。

## 实现注意

保留 ST_OFFLINE，让原技能、碰撞和 PracticeAIHero 在本地执行。不要把整个客户端伪装成 ST_MATCH 以跳过离线分支。大厅 B 背包和 Z/X/C/V 页面必须与练习场输入区分。

小地图隐藏钩子必须保存原方法并在训练时恢复。切场景复用 DebugManager.teleport 的异步加载回调；在完成回调以前禁止重复进入／离开。初始化重建对手而不向离地高度写入模型和行为坐标，避免物理层与行为层反复拉扯。

离线 Hero.getMaxLevel 原实现固定为 1，PlayerHero.cash setter 只允许减少，calcAllEqus 在离线直接返回。训练模式分别使用有范围的等级钩子、现有 `_cash_internal` 及本地数值属性合并；这些变更需要在返回大厅时恢复，不能写入普通大厅的永久属性。
